# 전략 실험실 (연구 탭, 2026-10-02)

연구 탭은 매일 쌓이는 아침 목록 기록으로 소유자의 아침 단타(9시 시가에 사서 +2.5~5%에서 판다)를 점검하는 화면이다.
그 전의 연구 카드(`studies.json`)와 일봉 백테스트 화면은 지웠다(소유자 요청). 연구 문서(`docs/studies/*.md`)와
백테스트 API(`/api/backtests`)는 그대로 있다. 판단 보조이고 사라·팔라를 말하지 않는다.

```
GET /api/lab   # backend/app/services/lab_service.py, 순수 계산은 backend/app/scoring/lab.py
python -m app.cli rule-reference --disclosures … --minutes …   # 3개월 기준표를 다시 만든다(호출 없음)
```

## 무엇을 재나

- **체결.** 9시 시가(09:00 봉 시가)에 산다. 익절·손절은 09:01부터 기존 진입·청산 연구와 같은 체결 모델(`entry_rules.r3`:
  목표가 호가 올림·목표가 체결, 손절은 1호가 아래 체결, 봉 시가가 이미 넘었으면 그 시가, 같은 봉이면 손절 먼저). 둘 다 안 닿으면
  10시 전 마지막 봉 종가. 손절 없음(`stop=None`)을 더했다. 비용 0.30%(`entry_rules.COST`).
- **도달.** "+X% 도달"도 같은 판정(`entry_rules.reached`, 고가가 목표가를 넘어야 함). 카톡·오늘의 관찰의 "보통"(`early_path`,
  고가 ≥ 목표)과 조금 다르다.
- **관측은 날짜.** 같은 날 종목들은 장 분위기로 같이 움직인다. 그날 해당 종목들의 평균 하나가 관측 하나이고 t·앞뒤 절반도
  날짜로 센다(`intraday_review`와 같다).

## 화면

1. **매일 성적표**: 목록 날마다 측정 수, 코스피·코스닥, +2.5% 10분·1시간, +5% 1시간 도달률, 대표 규칙 세 개(+2.5%·손절 없음,
   +2.5%·-2%, +5%·-1%)의 평균, 10시(비용 전), 뺀 종목과 이유. 누적 줄은 날짜별 평균의 평균.
2. **규칙 비교표**: 익절 2.5/3/5% × 손절 없음/1/1.5/2/3%, 시장별, 우리 목록과 3개월 기준표를 나란히.
3. **종목 조건 비교**: 우리 목록(시장, 목록 이유, 기술·재무·합계 점수 구간, 순위, 시가 갭, 전일 등락, 시장·갭)과 3개월
   기준표(시장, 갭, 전일 등락, 전일 거래량 배수, 주가, 공시 방향, 시장·갭).
4. **가설 추적**: 고정 가설 S1·S2와 아침 목록 가설 H1~H7(`intraday_service.report`).

비교표 두 개는 **탐색**이라 판정하지 않는다. 칸이 수백 개라 우연히 좋아 보이는 칸이 섞인다. 표시는 "표본 부족(날짜 20일 미만) /
앞뒤 같은 방향 / 앞뒤 갈림"뿐이다.

## 고정 가설 (2026-10-02 22:30 KST 고정, `lab.FROZEN_AT`)

스냅숏을 얼린 시각이 고정 뒤인 목록 날(10/6부터, 10/5는 휴장)만 센다. 문턱은 H1~H7과 같다: 20일까지는 기록만, 처음 60일로 한 번만 판정(평균이
예측 방향, |t| ≥ 2, 앞·뒤 절반 모두 예측 방향). 그 뒤로는 다시 묻지 않는다.

| | 질문 | 규칙 | 예측 | 고정 전 근거(3개월 기준표, 57일) |
|---|---|---|---|---|
| S1 | 시가 갭 -1% 미만 | +5% 익절·-1% 손절 | 비용 뒤 > 0 | -0.22%, t -0.93(근거 약함) |
| S2 | 시가 갭 +1% 이상 | +2.5% 익절·손절 없음 | 비용 뒤 < 0 | -1.15%, t -5.35, 앞뒤 같은 방향 |

S1은 소유자가 본 장면(10/1 한화솔루션: 갭다운 뒤 반등)과 첫 탐색(비용 0.2%, 손절선 그대로 체결)에서 나왔다. 기존 연구의 체결
모델과 비용 0.30%로 다시 재면 3개월 기준표에서 음수였다. 그래도 소유자의 질문이라 앞으로의 목록으로 다시 묻는다. 같은 탐색에서
나온 변형(갭 -3% 미만, 코스닥·갭다운)은 다중비교를 줄이려고 가설로 두지 않았다(비교표에서 볼 수 있다).

**3개월 기준표에서 비용 뒤 평균이 0보다 큰 규칙 칸은 없었다**(45칸, 가장 덜 나쁜 칸 코스피 +5%·-3% -0.50%). 손절·익절 숫자만
바꿔서 남는다는 근거는 아직 없다.

**선정 3(2026-10-06 목록부터, 10/5는 휴장)과 가설의 모집단.** 10/6부터 목록에서 판단 점수 40 미만·전일 +15% 이상을 뺀다. S1·S2는
고정 뒤 기록이 0건인 2026-10-02에 "제외 전 목록 40개"(뺀 종목 포함, 원래 순위 행)를 모집단으로 정했다 — 근거로 쓴 5일 기록이
40개짜리 목록이었기 때문이다. 규칙 비교표·종목 조건 비교도 40개로 내고 "목록 제외" 조건(남음 / 뺌: 점수 / 뺌: 전일 급등)을
하나 둔다. 매일 성적표는 화면·카톡에 나간 목록(남은 종목) 기준이고, 뺀 종목의 결과는 따로 한 칸에 둔다.

## 표본과 제외

- 우리 목록: PREOPEN_V2 목록 날의 목록 종목. 1분봉은 장 마감 뒤 16:20 작업이 받는다. 전일 종가·등락은 `prev_limits`와 같은
  정의(직전 세션 봉이 있을 때만, 최신 수정본, 세션 마감까지 끝난 봉, 목록을 얼린 시각까지 들어온 수정본)를 한 번에 읽는
  `prev_limits_many`로 구한다(직전 60일 안의 봉만 본다). `list-review`는 `ingested_before` 없이 읽어 갭이 다를 여지가 있다
  (5일치에서 차이 0건). 갭 구간도 다르다(여기 -3/-1/+1/+3, list-review -2/0/+2).
- 날짜별로 빼는 종목: 수집 전(그날 작업이 아직 그 종목까지 안 감 → 그날 "수집 중"), 부분 수집(PARTIAL·ERROR가 최신), 1분봉
  없음, 09:00 봉 없음(첫 체결이 늦음 — 개장 VI 등, 큰 갭 종목이 덜 잡힐 수 있다), 시초 잠김(09:30 전 모든 봉이 한 가격 — 시가에
  살 수 없었다).
- 지수 대형주도 넣는다(`list-review`는 묶음에서 뺀다). 한 종목이 여러 이유면 이유 줄 여러 개에 들어간다.
- 3개월 기준표: 공시 연구(2026-09-26) 파일의 2026-06-30~09-21 진입일, (종목, 진입일)은 한 번만, 공시 방향은 그날 가장 강한
  공시(`disclosure_study.strongest`와 같은 순서). 거래량 배수 = 전일 거래량 / 그 앞 20세션 평균(YFINANCE 일봉).
- 화면 값은 1분봉 수집 기록·목록·장중 요약의 마지막 id가 바뀔 때까지 서버가 계산해 둔 것을 준다.
