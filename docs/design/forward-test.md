# 포워드 기록과 검토 관문

[← README](../../README.md)

## 포워드 테스트 (4-8)

```
python -m app.worker          # 띄워 두면 아래 루프가 매일 돈다
python -m app.cli forward     # 지금까지의 기록. 읽기만 한다
python -m app.cli forward-run # 워커 없이 한 번 평가하고 오늘 후보 목록을 저장
```

뉴스에는 백테스트할 과거가 없다. 오버레이, 관련성 규칙, 후보 순위가 쓸모 있는지는 그것이
말한 것과 그 뒤 시장이 한 일을 적어 두는 수밖에 없다. 그래서 기록이 **빨리 시작할수록**
좋다. 네이버 검색은 최근 결과만 주므로 워커가 멈춘 날의 뉴스는 되살릴 수 없고, 그날의
판단도 남지 않는다.

**매일 루프 (워커).** 평일 16:40 KST, 그날 한국 세션이 끝났을 때 한 작업으로 순서대로:
가격(최근 한 달) → 지수(석 달) → DART 재무(2개 사업연도) → DART 사건 공시 → 채점과 오버레이·국면
→ 늦게 들어온 지수봉으로 빠졌던 국면 채움 → 신호 성과 평가 → 오늘의 후보 목록 저장 → 후보 성과 평가. 미국 가격은 화~토 07:00, SEC는 토요일 08:00. 휴장일은 건너뛴다.
아침 흐름(07:00 체인: 뉴스·공시 스윕 → 후보 풀 → 검색 추세 → 사전 수집 → LLM, 08:30 보충, 08:40 관찰용 점수, 08:50 목록), 저녁 뉴스 스윕(16:00, 공시 포함), KIS 분봉(16:20), 지수 분봉(장중 매시)은 따로 돈다.

**성과는 백테스트와 같은 규칙으로 잰다.** 신호는 마감 시점의 판단이므로 진입은 다음 세션
시가(`earliest_execution_at`), 청산은 진입 세션을 1로 세어 1·5·20번째 세션의 종가다.
판단이 없는 ABSTAINED는 재지 않는다. 같은 판단 시점의 신호가 재채점으로 여러 개면 처음
것만 센다. 초과수익은 같은 날 같은 시장에서 판단한 종목들의 평균 대비다. 후보는 목록을
뽑은 뒤 첫 시가에 진입하고, 추적 밖 종목이라도 가격만 받아(`FORWARD_` 실행 이름) 잰다.
승격은 하지 않는다.

**리포트는 행동별, 오버레이 부호별(±1점, 현재 오버레이 버전·해석 모델·프롬프트의 것만), 시장 국면별, 검색 관심도별, 후보 순위별, 후보의 국면·관심도별로** 표본 수, 서로 다른 날의 수,
평균, 중앙값, 적중률, 초과수익을 보여준다. 날 수는 달력일로 센다(한국과 미국이 같은 날 진입해도 하루). 몇 주 치는 독립적인 날 몇 개일 뿐이다. 평균보다
표본 수를 먼저 읽는다.

## 검토 관문과 오버레이 결정 규칙 (4-8)

```
python -m app.cli review   # 관문까지 남은 날, 좋은·나쁜 뉴스의 초과수익, 결정 규칙, 반감기 점검. 읽기만 한다
```

**결정 규칙은 기록이 비어 있을 때 정했다.** 결과를 본 뒤 고른 기준은 결과에 맞춰진 기준이다. 그래서
기준을 `app/scoring/review.py`에 먼저 쓰고 커밋했다. 커밋 시각이 기준이 먼저였다는 증거다.

**한국 진입일 단위로 센다.** 오버레이는 한국 뉴스만 읽으므로 검토도 한국 기록으로 한다. 같은 날
판단한 스무 종목은 같은 시장을 겪으므로 관측 하나다. 모든 통계는 하루 안에서 먼저 평균하고, 날들
사이에서 평균과 표준오차를 낸다. (처음에는 진입 시각으로 날을 세어, 한국과 미국이 같은 날 진입하면
이틀로 셌다. 석 달 관문이 한 달 반 만에 찰 뻔했다.)

| 관문 | 조건 | 하는 일 | 가장 이른 날(매 세션 기록 시, 추정) |
|---|---|---|---|
| 한 달 | 5세션 성과가 있는 진입일 20일 | 읽기만, 결정 없음 | 2026-11-03 |
| 석 달 | 같은 진입일 60일 | 오버레이 결정. 처음 60일로 한 번만 | 2026-12-30 |
| 여섯 달 | 처음 60일에 뉴스가 모자랐을 때만, 처음 120일 | 단 한 번의 연장. 그래도 모자라면 "아니오"로 확정 | 2027-03-31 |

**결정은 고정된 표본으로 한 번만 한다.** 60일이 지난 뒤 매일 다시 보면, 우연히 t ≥ 2가 나올 때까지
같은 질문을 반복하는 셈이다. 그래서 처음 60 진입일로 정하고, 뉴스가 모자랄 때만 한 번 120일로
늘린다.

**오버레이가 행동을 바꾸자고 제안할 수 있는 조건.** 결정 표본의 5세션 초과수익으로 넷 다:

1. 좋은 뉴스(+1점 이상) 날과 나쁜 뉴스(−1점 이하) 날이 각각 20일 이상
2. 좋은 뉴스 − 나쁜 뉴스 차이가 양수이고 t ≥ 2 (두 쪽이 같은 날을 공유하는데 표준오차는 독립인
   것처럼 합친다. 상관을 무시하는 쪽이며, 알고 쓰도록 적어 둔다)
3. 진입일 중앙값으로 나눈 앞·뒤 절반 모두 차이가 양수(각 절반에 양쪽 5일 이상. 모자라면 실패)
4. RISK_ON과 그 밖의 알려진 국면(UNKNOWN 제외) 모두 차이가 양수(한쪽이 5일 미만이면 "검증 안 됨"으로
   적고 불리하게 세지 않음)

통과해도 켜지지 않는다. 새 전략 버전을 제안할 자격이 생길 뿐이고, 그 버전은 행동 분포를 세어
임계값을 확인한 뒤, 홀드아웃을 건드리지 않고 평가한다. 5세션으로 정한 이유는 반감기가 1~10일이기
때문이다.

**반감기 점검은 탐색용이다.** 오버레이의 각 사건을 판단 시점의 나이(1일 미만, 1~3일, 3~7일, 7일
이상)로 나누고, 초과수익에 사건 방향의 부호를 곱해 평균한다. 뉴스가 가격을 움직이고 옅어진다면
나이가 들수록 줄어든다. 절반이 되는 나이가 반감기가 말해야 하는 값이다. 다음 파라미터 버전의
근거가 될 뿐, 자동으로 바꾸지 않는다.
